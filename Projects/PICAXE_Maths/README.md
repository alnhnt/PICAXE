# PICAXE Maths

This project contains maths software and documentation for PICAXE BASIC.

* [VeryFastDivision_32BitByWord.pdf](./Documents/VeryFastDivision_32BitByWord.pdf) describes how 300 ms of binary long division can be replaced with 30 ms of a nibbling technique, without touching clock speed.
* [VeryFastDivision_32BitByWord.bas](./Documents/VeryFastDivision_32BitByWord.bas) provides the very fast division software in its testing framework and along with detailed inline information.
